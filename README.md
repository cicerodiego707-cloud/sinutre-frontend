
# SiNutre

Sistema web de acompanhamento nutricional desenvolvido para auxiliar os usuários no registro e gerenciamento de refeições, acompanhamento de metas calóricas e monitoramento de indicadores relacionados à saúde.

## Tecnologias utilizadas

- React 19
- TypeScript
- Vite
- Tailwind CSS
- daisyUI
- Node.js
- Express
- Prisma ORM
- PostgreSQL (Supabase)

## Funcionalidades desenvolvidas

- **01.** Edição de alimentos cadastrados.
- **02.** Exclusão de alimentos cadastrados.
- **03.** Validação de dados no cadastro e na edição de alimentos.
- **04.** Cadastro de dados complementares do usuário, incluindo meta calórica, altura e peso, com validação.
- **05.** Alteração dos dados complementares do usuário.
- **06.** Exibição da meta calórica diária no dashboard.
- **07.** Sinalização quando a meta calórica diária é ultrapassada.
- **08.** Página de métricas com informações sobre IMC e média calórica.
- **09.** Exibição do IMC e sinalização da faixa correspondente.
- **10.** Cálculo da média calórica dos últimos sete dias e comparação com a meta.
- **11.** Funcionalidade de logout.
- **12.** Personalização das cores da interface.

## Funcionalidades adicionais

- Edição e exclusão de refeições cadastradas.
- Atualização dos alimentos e quantidades que compõem uma refeição.
- Registro da data da última atualização de uma refeição.
- Tratamento de sessões inválidas, com redirecionamento para a tela de login.
- Autenticação de usuários e separação dos dados por conta.
